# 人工叡智ガードレール・プロンプト拡張機能

[English Version](README.md)

これは、プロンプトのみで動く、Chrome／Edge向けの開発者用拡張機能です。

ページの内容を読み取らず、AIのAPIも使用しません。

## インストール

1. このリポジトリを**Code → Download ZIP**でダウンロードします。
2. 解凍します。
3. `chrome://extensions`または`edge://extensions`を開きます。
4. **デベロッパーモード**をオンにします。
5. **パッケージ化されていない拡張機能を読み込む**をクリックします。
6. この`extension`フォルダを選択します。

## 使い方

拡張機能を開き、**Copy preview content**をクリックします。

プロンプトは、あなたが選んだ場合にのみ、AIに貼り付けてください。
